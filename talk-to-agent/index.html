Publish and talk to agent

Two changes. Versioning and the published confirmation become a single modal. Talk to agent takes people straight from there, or from the n8n Chat settings, to the n8n homepage with that agent selected. Click through both below.

1 — One publish modal

See what publishing does and publish. Naming the version and describing changes sit behind Add versioning, so the common case stays short. Talk to agent is part of the same modal, so there is no second confirmation screen.

Any changes you make to this agent will not be published until you publish it again.
  • Versioning is collapsed by default. If it stays closed, the version is named automatically (Version 3), so nothing is required to publish.
  • The message moves to the future tense, because it now appears before publishing: it says what publishing will do instead of confirming it afterwards.
  • Publish and talk to agent is the primary action, since talking to the agent is the next thing people want. Publish alone stays one click away and returns to the builder.

2 — Talk to agent from the n8n Chat settings

The same button, in the footer of the modal that opens from the Channels row. It only shows when the agent is published, because that is the only time this modal opens in Edit mode.
