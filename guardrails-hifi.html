Rebuilt on the Access policies modal, which is the closest thing that ships. Its anatomy is a grouped card of rows, each with a name, a line of detail and a state on the right that opens a menu — ✓ Allowed ▾. That's a better fit than the tags I had: a tag can only say a guardrail is attached, where a row says what it will do when it fires, which is the thing you came to check.

It also puts the two halves of this pane in the same language. Tool permissions and guardrails are now the same component with different contents, so the pane reads as one list of decisions about this tool rather than a settings block followed by a tag field.

The primary button is dark, not pink. That's what the real modal does — Done is a black pill — and it matches --color--primary: neutral-900 in the new tokens. Worth confirming, because --button--color--background--primary still resolves to pink-500, so the DS currently says two different things.
