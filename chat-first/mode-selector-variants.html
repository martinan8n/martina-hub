Build / Test selector — three ways to make it more prominent

Each one borrows from something already live in the product. Same composer, same two modes; only the selector changes. Build is shown active in all three.

A — Tinted pill

Takes the live “Finish setup” treatment: accent text on a soft tint of the same hue, pill-shaped. Drops the grey track, so the active mode is the only filled thing in the row. Violet because that’s the colour the product already uses for assistant-driven work.

B — Tinted pill with the breathing glow

Variant A plus the halo from the “Brewing…” indicator, on a 3.2s breathe loop. Reads as live and a bit playful. Worth deciding whether it should pulse all the time, or only while the assistant is actually working — permanently animated UI gets tiring.

C — Lifted above the field

Moves the selector out of the icon row onto its own line at the top of the composer, where you read before you type, and spells out what the mode does. The most prominent of the three, and the only one that explains itself.

Changes the agent

Not used here, but available from the same source: the “Brewing…” pill is one of ten labels that rotate every 5s (Imagining, Tinkering, Pondering, Hatching, Concocting, Sparkling, Noodling, Percolating, Doodling), with a 4-square grid spinner — that belongs on the agent while it’s being built, not on the selector.
